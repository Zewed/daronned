# Daronned

Un RPG parodique de cuisine en 2D, au tour par tour, jouable dans un navigateur sur ordinateur.

## Lancer le jeu

```bash
pnpm install
pnpm dev
```

## Vérifier

```bash
pnpm typecheck
pnpm test
pnpm build
```

## Où est quoi

- `.veebee/` : le produit, ses règles, sa charte et ses tickets.
- `CONTEXT.md` : les mots du jeu.
- `src/` : le jeu.
- `tests/` : les tests, écrits depuis ce que fait le joueur.
