# 0005 : partir du pari ou de ce dont il dépend

**Un côté** : le plus gros pari est le potager, donc il devrait être défini en premier.

**L'autre côté** : les légumes du potager suivent les règles du combat, donc le combat passe logiquement avant.

**Le conflit** : le morceau qui porte le pari dépend d'un autre morceau.

**Choix** : le découpage par ce qu'on fait, avec le potager en premier.

**Pourquoi** : c'est le pari qui doit contraindre le reste. C'est un ordre de lecture, pas un calendrier.
