# 0004 : ce que coûte un Daronned

**Un côté** : un Daronned fait perdre seulement l'xp du combat.

**L'autre côté** : un plat immangeable est un Daronned et fait recommencer le chapitre.

**Le conflit** : recommencer le chapitre efface aussi la chasse des ingrédients, donc le prix n'est pas le même.

**Choix** : deux coûts selon l'échec. Combat perdu, xp du combat perdue. Plat immangeable, chapitre à refaire.

**Pourquoi** : les deux réponses sont gardées, chacune pour son type d'échec.
